# ✈️ Plane Management System  

A **Java console-based application** for managing plane seat bookings, cancellations, and ticket information. Built with **OOP concepts**, **file handling**, and a **menu-driven interface**.  

---

## 🚀 Features  
- Book and cancel seats  
- View seating plan (`O` = available, `X` = booked)  
- Find first available seat  
- Print all tickets & total sales  
- Search for a ticket  
- Save/Delete ticket info as `.txt` files  

---

## 💳 Ticket Prices  
- Seats 1–5 → £200  
- Seats 6–9 → £150  
- Seats 10+ → £180  

---

## 📂 Files  
- `Person.java` → Passenger details  
- `Ticket.java` → Ticket + File handling  
- `PlaneManagement.java` → Main program  

---

## ▶️ Run the Program  
```bash
javac Person.java Ticket.java PlaneManagement.java
java PlaneManagement
